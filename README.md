# Isaac Weintraub Research Archive

This repository hosts my research archive and publication explorer at https://isaacew.github.io.

The current site is a single-page, dark glass-themed interface built with plain HTML, CSS, and JavaScript:

- index.html – main page layout and sections
- styles.css – dark glass theme, layout, and motion
- app.js – client-side logic for loading publications, filters, hero behavior
- publications.json – structured publication metadata

Legacy Astro-based content and template files have been removed in favor of this simpler, custom archive.
